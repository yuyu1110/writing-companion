# 写作伴侣 · Writing Companion

一个以散文随笔为主、兼顾小说的中文写作辅助 Skill：陪作者构思、质疑文字、查找范例，并把一次修改变成可以独立运用的写作经验。

**默认由作者执笔。** 当你说“帮我看看这一段”，它先指出具体问题、说明判断依据，再提供方向和短示范。只有你明确要求改写或续写时，它才给出候选稿；候选稿不会自动替换原稿。

## 能做什么

| 场景 | 协作方式 |
|---|---|
| 散文与随笔 | 讨论经验、细节、语言节奏与表达目的，保护个人声音 |
| 小说构思与续写 | 梳理人物欲望、关系、冲突、叙述安排及已确认设定 |
| 审稿与改稿 | 质疑落到具体文字，区分文本事实、阅读效果和审美选择 |
| 书库对读 | 从自己的资料中寻找写法，核验上下文，给出章节与 Markdown 行号 |
| 写作教学 | 提问、解释和短示范随实际困难调整；需要选择时一次只问一个问题 |
| 作品整理 | 保留原稿，区分候选版本、采纳版本与定稿，保存可接续的进度 |

书库由使用者自行提供。本仓库包含规则、检索脚本和空白工作区模板，**没有附赠文学作品全文，也没有作者的私人稿件或档案**。

## 从哪里开始

1. 阅读 [安装与使用](docs/getting-started.md)，安装 `skills/writing-companion`。
2. 可以直接拿一段文字开始；需要长期书库和进度时，再复制空白工作区模板。
3. 在新对话中明确调用这个 Skill，例如：

> 使用 $writing-companion。请先判断这段文字想表达什么，再指出最影响效果的一处问题，解释理由，给一两句示范。先不要替我改全文。

不同客户端的 Skill 选择方式可能不同，可直接使用界面中的 Skill 选择器。安装路径和调用方式参考 [OpenAI 官方文档](https://learn.chatgpt.com/docs/build-skills)。

## 一次反馈是什么样

以本项目专门编写的示例句为例：

> 他走后，我非常难过，整个屋子都是悲伤。

助手可以先提出判断：“这里两次直接命名情绪，却还没有让读者看见这次离别独有的痕迹。”随后解释抽象概括与具体细节各自的作用，查找用户书库中相关的真实范例，再给出明确标注的原创短示范：

> **虚构示范，供比较：** 我收了两只碗，才想起明早只用洗一只。

最后只提出一个当前需要作者决定的问题：“你希望这一段更像当时的切身感受，还是事后的回望？我推荐先贴近当时，因为具体动作能承接刚刚发生的离别。”

这只是说明反馈方式的原创例子，并非任何书籍引文或真实辅导记录。若原稿属于纪实，示范中的细节不能当成作者真实经历；实际辅导应先核对。没有查到书库证据时，助手必须说明，不能编造名家原句来支持建议。

## 能力边界

当前检索采用 SQLite FTS5、中文双字词元和手动概念词组。它能找到字词线索，不能保证找到所有语义相似场景。阅读卡只代表实际核验过的范围；入库和建立索引都不意味着模型已经读懂整本书。

Skill 的教学与协作方式由宿主模型执行，需要在真实写作中持续验证。脚本在本机运行，不调用模型 API；把检索片段提供给 AI 后，仍按所用客户端的数据处理方式运行。
