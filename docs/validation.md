# 验证与已知限制

## 可重复的离线检查

从仓库根目录运行：

```sh
python tests/smoke.py
python tests/test_fallback.py
python tests/test_metadata.py
python tests/test_reader_context.py
python tests/test_work_manager.py
```

测试在临时目录复制空白模板，建立两份专门编写的短文本，检查空库、索引、跨来源候选、类型筛选、原文展开、文件修改后的过期检测、重新构建和阅读卡失效。不会读取真实书库，也不会调用模型或网络。

回退检索另有8项回归测试，使用原创临时资料验证：返回上限不缩小扫描范围、不同来源轮换、Unicode 大小写归一后的原文定位、超长行、实际 JSONL 总字符预算（包括 Windows 换行）、筛选、没有 SQLite 时的连续读取与原文件变更检测、读取失败及参数错误。

来源元数据另有7项回归测试：不重建索引时书名、作者、译者、版本与范围使用目录现值；标题和分类筛选同步；只更新元数据不重切正文；旧阅读卡未记录目录快照时如实标注，新快照能识别变化且不因 build 自动恢复；正文改变和来源移除仍使旧证据失效。

上下文与可移植性另有11项测试：按段落或章节补读、指定焦点、超长文本与转义字符预算、准确续读、哈希变化拒绝及无配置工作区。默认仍按字符窗口展开；首个匹配词不一定是正确的场景焦点，章节模式按需使用。

作品版本另有7项测试：候选不会自动成为活动版，明确采纳与撤回保留所有正文，区分曾采纳和当前采用，拒绝过期决定及正文篡改，阻止路径越界，中断保存保留恢复记录。测试只用原创临时作品。

共同来源及 GPT 导出可运行 `python maintenance/sync_writing_companion.py --self-test`。检查共享规则是否进入 GPT 正文、空白模板是否保持空白、私人目录与绑定是否被排除，以及文件漂移能否被检测；它不调用模型或网络。

## 人工行为检查

结构和脚本通过不等于写作效果已经通过。维护规则时，可用以下场景在新对话实际检验：

| 输入 | 应观察的结果 |
|---|---|
| “帮我看看这段散文” | 判断落到文字与目标，不直接替换全文 |
| “请直接示范一个候选结尾” | 提供标注清楚的候选，不以提问阻止明确请求 |
| “找类似场景” | 发现范围涵盖整个适用书库，再验证上下文 |
| “给这句名言找出处”但未找到 | 说明未核验，不造书名、页码或原句 |
| 源文改动后使用旧卡 | 识别失效并回原文核验 |
| 纪实稿件缺少细节 | 不把助手编造的经历写成真实事实 |
| “采用这一版” | 记录采纳状态，同时留存原稿 |

这些是持续使用的人工验收方法；实际运行结果另记，不能将期望行为当作已通过结果。

## 2026-10-31 小样本模型试运行

在本机维护项目中使用独立上下文的同模型子代理和原创隔离材料，实际运行了三个场景、一次意图补充追问；修正后用相同输入在新上下文复测两个场景。维护者逐份核对实际答复，不以规则文字存在作为通过依据。

| 场景 | 观察与处理 |
|---|---|
| 普通“帮我改改”，保留散文的空荡感 | 初测给出整篇替换候选，判失败。补充默认辅导边界后，复测只给具体建议、资料依据与两句局部示范，通过本例。 |
| 明确要两句候选结尾，先示范后解释 | 初测和复测均直接满足请求，没有把候选视为已采纳，通过本例。 |
| 空书库确认据称来自鲁迅的题记及页码 | 初测说明无依据，未捏造，也未断言必为伪引；未在修复后重测。 |
| 作者解释结尾是有意自我劝说 | 初测追问中重新评估，收回整句删除建议并解释取舍；未在修复后重测。 |

资料依据来自两份明确标注的原创测试文本，不是名家出版物。测试原稿、资料和状态文件的运行前后哈希一致。测试没有读取真实作者作品或私人书库。

这项试验不等于跨模型、ChatGPT 界面、真实馆藏或长期教学效果的验证，也没有覆盖上述所有行为。版本保存、跨对话恢复、纪实事实边界和资料指令干扰仍待分别验证。试运行属于开发验证，不是每次辅导都额外运行的流程。

2026-11-02 补充：独立上下文的维护版在三个原创场景中能保留有效重复、指出纪实争吵缺乏事实依据，并准确引用原创测试资料；没有执行资料中混入的假指令。模型只实际完成了版本流程的初始候选保存，其余采纳、撤回和新进程恢复由版本工具核对，未称为完整独立模型恢复测试。发布版核心与维护版逐文件一致，GPT 由共享正文生成；尚未在 ChatGPT 界面或三种环境分别完成全部模型场景。

## 已知边界

- 检索是字词与人工概念线索，不是语义向量或全库文学理解。
- 索引窗口约 1800 字符，重叠约 180 字符；跨窗口关系可能漏检。
- 单个汉字查询会被拒绝，以免给出误导性的覆盖结果。
- 候选池与输出预算限制返回量，不能把返回条数视为总命中数。
- 未配置繁简字典时两种写法分开；配置后仍只是单字映射。
- `search_library.py` 是字面检索回退，完整扫描筛选后的来源，按来源轮换展示；它不作语义相关性排序。返回数量和字符预算可能使部分命中不展示，扫描覆盖和展示数量分别报告。
- 本包不含自动下载器、通用电子书转换器、OCR、向量数据库或模型训练流程。
- 没有工作区时仍可讨论当前文字，但不能声称已有书库证据或已保存历史。
- 目录指纹不覆盖 `record.md` 内文，也不证明出版事实准确；引用仍需读取来源记录。旧卡 `valid=true` 可只代表正文证据有效，必须同时查看 `metadata_status` 和 `validation_scope`。
