## 可以直接使用的 Markdown 记录模板

以下模板按实际任务选用，字段可以删减。未知填“未知”，待决定填“待定”，没有材料填“未提供”；不能为填满表格编造信息。作品正文应完整另存或直接附在记录后，卡片与摘要不能替代它。

### A. 作者协作卡

```markdown
# 作者协作卡
- 更新时间：
- 已明确的主要文体：
- 已明确的反馈方式：
- 作者确认希望保留的表达：
- 作者希望调整的习惯：
- 本次临时要求：
- 各项偏好的确认来源或日期：
- 尚未确认的事项：
```

### B. 作品卡

```markdown
# 作品卡
- 作品 ID：
- 标题与文体：
- 状态：构思 / 写作中 / 修改中 / 作者确认完成
- 纪实或虚构边界：
- 已确认的表达目标：
- 原稿的位置或附文标识：
- 活动版本与正文位置：
- 候选版本及采纳状态：
- 作者希望保留的部分：
- 当前最重要的问题：
- 已确认的决定：
- 待定事项：
- 下一步：
```

### C. 小说接续卡

```markdown
# 小说接续卡
- 所属作品与活动版本：
- 目前写到哪里：
- 当前人物欲望与阻碍：
- 已确认人物、关系、时间线与视角：
- 人物与读者各自知道什么：
- 已建立但尚未兑现的线索：
- 最近停笔的具体位置：
- 未采纳的候选构思：
- 已知矛盾及各自依据：
- 下一个能实施的动作或场景：
- 继续写前需要作者决定的一件事：
```

### D. 版本与采纳记录

```markdown
# 版本记录
- 作品 ID：
- 版本 ID：
- 基于哪个版本：
- 正文位置或附文标识：
- 来源：作者 / 助手 / 混合
- 变化及目的：
- 状态：原稿 / 候选 / 活动版本 / 作者确认定稿 / 已撤回
- 作者采纳或撤回的原话、消息标识或日期：
- 尚未确认的新增事实或设定：
- 实际保存状态与位置：
```

### E. 来源与版本卡

```markdown
# 来源卡
- 来源 ID：
- 题名、作者：
- 版本、译者与出版信息：
- 原文件或可访问来源：
- 当前可读文件及定位方法：
- 收录范围：全文 / 某版本全文 / 选集 / 节选 / 缺卷 / 待核实
- 提取状态与转换方式：
- 实际抽查、已读或已分析的范围：
- 已知缺陷与不同版本差异：
- 文件版本标识、更新时间或实际计算的哈希：
- 附件引用标记或可复查锚句：
```

### F. 阅读卡与技法卡

```markdown
# 阅读卡
- 卡片 ID 与主题：
- 类型：写作指导 / 散文 / 小说场景 / 其他
- 来源 ID、书名、作者、版本与译者：
- 已实际读到的章节或段落：
- 原文定位与必要短引：
- 原文、转述、转引或自译的身份：
- 所讨论的具体情境或语言处理：
- 作用机制与文本证据：
- 与当前作品相似和不同的地方：
- 适用条件与局限：
- 其他来源的支持、分歧或不同条件：
- 可尝试的动作或练习：
- 作者是否采纳：
- 关键词：
- 证据核验时间与版本状态：
```

### G. 风格参照卡

```markdown
# 风格参照
- 样本作品、版本与范围：
- 原文位置和短例：
- 具体表达特点：
- 在本处产生的效果：
- 适用文体、叙述者或时期：
- 状态：样本观察 / 作者确认保留 / 作者希望调整
- 作者确认依据：
- 新稿相对样本的变化、收益与代价：
```

### H. 练习记录

```markdown
# 练习记录
- 目标与原稿问题：
- 题目：
- 作者作答：
- 使用过的帮助：观察提示 / 缩小范围 / 示范 / 直接解释 / 独立完成
- 反馈中的文本证据：
- 产生的变化与仍待选择之处：
- 回到原稿后的应用：
- 后续新材料中的独立运用证据：未出现则留空
- 判断范围与不确定性：
```

### I. 书库与作品总目录

```markdown
# 写作资料目录
## 可访问来源
| 来源 ID | 题名与版本 | 实际范围 | 可读位置 | 阅读或核验状态 |
|---|---|---|---|---|

## 作品
| 作品 ID | 标题 | 状态 | 活动版本 | 正文位置 |
|---|---|---|---|---|

## 阅读卡与技法卡
| 卡片 ID | 主题 | 来源及已读范围 | 卡片位置 | 是否需重新核验 |
|---|---|---|---|---|

## 练习
| 练习 ID | 目标 | 作答位置 | 所需提示 | 后续迁移证据 |
|---|---|---|---|---|

## 待处理或不可访问资料
| 材料 | 当前缺口 | 下一步 |
|---|---|---|
```

### J. 带到新对话的接续包

```markdown
# 写作伴侣接续包
- 摘要日期：
- 本轮实际使用的协议版本：
- 本次任务与主要文体：
- 当前活动作品、版本与正文位置：
- 作者已经确认的目标与偏好：
- 已经完成且能核对的工作：
- 作者已采纳的决定：
- 仍只是候选的文字、情节或建议：
- 当前最重要的未决问题：
- 下一步可实施的动作：
- 使用过的资料、版本、实际已读范围与定位：
- 阅读卡或引文需要重新核验之处：
- 实际保存的文件与位置；没有则明确写未保存：
- 新对话必须一并提供的原稿、活动版本或资料：
- 当前缺失、冲突或无法确认的内容：

请在新对话中读取本摘要与随附原文，继续当前任务。
摘要不代替作品正文，也不证明其他对话中的书库已经可访问。
```
