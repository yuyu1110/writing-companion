# 资料与阅读卡管理

用于导入资料、维护来源和保存可复用的阅读成果。日常查书、对读和引用见 [书库检索与引用](retrieval.md)；归档与版本保存遵循 [工作区与记录](workspace.md)。

## 导入正文与来源

保留原文件，将可读取正文统一转换为 UTF-8 Markdown。记录作者、书名、版本或译者、来源位置及实际获取范围；缺失字段填“未知”，不补造出版信息。来源字段和路径约定见 [记录的最小内容](workspace.md#记录的最小内容)。

按工作区 `library_policy` 执行准入标准。当前允许不同版本、选集、节选和缺卷，须在来源记录中标明范围与差异；书单 `booklist` 记录需求，`catalog.json` 的 `sources` 记录可用资料。未准入材料留在 `pending-sources`，不参加正常检索。

先确认提取能力，抽查开头、中间、结尾、章节次序和段落。PDF、扫描件或图片没有可靠提取结果时标为“待提取”；缺页、乱码、未 OCR 的图中文字等限制保留在记录中。不能把摘要替代正文，也不能把文件标题当成完整性证明。

状态区分“已登记、已提取、部分分析、已分析指定范围”。只标记实际完成的读取范围；已可检索不等于已通读、掌握或训练过模型。

## 阅读卡与技法卡

有复用价值的定向阅读可以保存为独立卡片，不给每次查询或每个段落自动建卡。先查已有卡片，同一问题优先补充，有不同解释或用途时再新建。卡片保存的是助手可讨论的分析，不能将解释升级为公认事实。

| 内容 | 记录要求 |
|---|---|
| 身份与定位 | 来源 ID、书名/版本、实际已读行段、文件 SHA-256、必要短引 |
| 方法或场景 | 技法名称与作用机制；文学场景另记情境、人物关系、叙述安排与意象 |
| 使用条件 | 适用文体、关键词、局限、与其他主张的差异 |
| 作品关联 | 可尝试的练习或当前作品应用；明确属于候选建议还是作者已采纳 |

只记录实际读过的部分，不自动为未读作品生成情节摘要。资料变化后重新定位引文、更新摘要和受影响卡片。新卡加入工作区 `reading_cards`；`guidance_index` 是人工导航，不代替独立卡片及原文。具体路径与保存步骤见 [工作区与记录](workspace.md)。

## 关联与维护

一个来源可关联多个技法，一个技法也可比较多个来源。按证据记录互相支持、方法不同、条件不同、解释分歧及作品应用；保留来源 ID 和原文位置，不为凑关联编造关系。不同年代和审美的文学主张可以并存，不因较新就淘汰旧材料。

导入或修改原文后运行 [library_reader.py](../scripts/library_reader.py) 的 `build` 命令增量更新索引。索引是可重建的派生文件，构建不等于模型阅读全文。索引尚未更新时的回退检索及过期状态处理见 [检索工具与结果边界](retrieval.md#检索工具与结果边界)。

批量入库或维护时，检查本次涉及的路径、重复来源、出处、失效引用、孤立卡片和未标明分歧。修正时保留必要的变更说明。外部文献、作者原作和助手示范保持不同来源身份；入库不授权公开分享、上传或外发。
